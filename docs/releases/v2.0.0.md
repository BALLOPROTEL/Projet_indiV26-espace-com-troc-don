# V2 — Plateforme 2-en-1

Cette release consolide la plateforme **La Petite Maison de l’Épouvante** autour de deux parcours réels : **Boutique** et **Échanges / dons / troc**.

## Fonctionnalités livrées

- authentification et rôles Keycloak ;
- publication, modération et cycle de vie DON/TROC ;
- galeries MinIO ;
- propositions, transactions et double confirmation ;
- conversations privées ;
- favoris et notifications ;
- catalogue Boutique, panier, commandes et réservation de stock ;
- SEO dynamique des annonces ;
- refonte UX/UI conforme au prototype V2 ;
- pages légales et politique de confidentialité ;
- export structuré des données du compte ;
- workflow d’anonymisation distribuée Catalog / Marketplace / Notification / Commerce ;
- Fanzines persistants et administrables ;
- Festival / actualités persistants et administrables ;
- Contact et demandes Privacy persistants ;
- catégories, ville volontaire, état des annonces et filtres ;
- signalements utilisateurs et file de modération.

## Sécurité et gouvernance

- endpoints internes Privacy non exposés par le Gateway public ;
- token interne partagé uniquement entre services concernés ;
- RBAC USER / MODERATOR / ADMIN ;
- CI lint / typecheck / tests / Prisma / microservices / navigateur ;
- protection de `main` auditée et durcie via procédure dédiée ;
- release créée uniquement depuis le SHA réellement présent sur `main`.

## Hors périmètre de certification V2

**Stripe est volontairement ignoré pour cette release finale.** Le code de paiement test existant n’est pas utilisé comme critère de validation de la V2 et aucun paiement live n’est déclaré opérationnel.

## Exploitation

Avant une publication publique réelle, renseigner les coordonnées légales de l’éditeur/responsable/hébergeur, appliquer la politique de conservation retenue et valider l’environnement de production.
