# LOT 10-B — Feuille de répétition chronométrée

> À remplir pendant une répétition réelle. Ne jamais marquer PASS sans avoir réellement chronométré.

## 1. Cible

- Durée totale : **18 min 30 à 19 min 30**
- Marge : **30 s à 1 min 30**
- Démo live : **5 à 6 min**
- Dépassement maximum toléré avant correction : **20 min**

## 4. Validation finale

La répétition est validée seulement si :
- [ ] présentation terminée en <= 20 minutes ;
- [ ] démo terminée en <= 6 minutes ;
- [ ] aucun secret affiché ;
- [ ] aucun dépannage improvisé ;
- [ ] transition Plan A → Plan B testée ;
- [ ] transition Plan B → Plan C testée ;
- [ ] les limites techniques sont expliquées clairement ;
- [ ] la conclusion tient en <= 1 minute.

## 5. Vidéo de secours — scénario d’enregistrement

Durée recommandée : **3 à 5 minutes**.

Séquence :
1. catalogue public + galerie ;
2. connexion USER ;
3. demande DON/TROC ;
4. compte propriétaire : acceptation/refus ;
5. état transaction ;
6. ADMIN dashboard ;
7. USER refusé ADMIN ;
8. écran final avec preuve du statut.

Avant enregistrement :
- notifications OS désactivées ;
- e-mails/onglets personnels fermés ;
- aucun mot de passe auto-rempli visible ;
- résolution lisible ;
- curseur visible ;
- audio compréhensible si narration ;
- aucun terminal avec secret.

Après enregistrement :
- lire la vidéo en entier ;
- vérifier audio/image ;
- vérifier qu’aucun secret n’apparaît ;
- stocker une copie locale et une copie de secours ;
- noter le SHA de la version démontrée.
